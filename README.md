# По порядку — To-Do List

Тестовое задание: простой адаптивный сайт для управления задачами. Интерфейс на русском языке, без фреймворков и внешних зависимостей.

**Сайт:** https://sxolmanskix-code.github.io/Test_site/

**Репозиторий:** https://github.com/sxolmanskix-code/Test_site

## Возможности

- Создание задачи кнопкой «Добавить» или клавишей Enter.
- Отметка выполнения и возврат задачи в работу.
- Удаление задач.
- Сохранение списка и статусов в `localStorage` после каждого изменения; восстановление при перезагрузке.
- Фильтры «Все», «В работе», «Готово», счётчики и прогресс.
- Адаптивный интерфейс, управление с клавиатуры, подписи для скринридеров.
- Проверка пустого ввода, безопасный вывод текста, сообщение при недоступности хранилища.

## Запуск

Установка зависимостей и сборка не нужны. Из каталога проекта запустите:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Для размещения на хостинге достаточно файлов `index.html`, `styles.css`, `app.js` и `favicon.svg`.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку **main**, каталог **/(root)** и сохраните настройки.

Адрес после включения Pages: https://sxolmanskix-code.github.io/Test_site/

## Проверка по ТЗ

В браузере проверены добавление кнопкой и Enter, переключение статуса, фильтр выполненных задач, восстановление списка и отметок после перезагрузки, сохранение удаления, отклонение ввода из пробелов и мобильный вид шириной 375 px. Синтаксис JavaScript проверен командой `node --check app.js`.

1. Добавьте две задачи, одну кнопкой, другую через Enter.
2. Отметьте первую выполненной; переключите фильтры и верните задачу в работу.
3. Перезагрузите страницу: текст, порядок и отметки должны сохраниться.
4. Удалите задачу и перезагрузите страницу: она не должна появиться снова.
5. Проверьте ввод одних пробелов, длинного текста, текста `<script>alert(1)</script>`, мобильный экран и навигацию Tab/Space/Enter.

Данные хранятся только в текущем браузере для адреса сайта, без сервера и синхронизации между устройствами. Очистка данных сайта удаляет задачи. При сбое записи показывается предупреждение; повреждённые сохранённые данные не перезаписываются.
